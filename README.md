# زیمر — دموی تعاملی تولید پوشاک

Interactive demo of Zimmer, a modular ERP, configured for a garment manufacturer (پوشاک مهرآذین، پاییز ۱۴۰۵). Persian, RTL, frontend only.

```bash
npm install
npm run dev
```

## Demo script

1. **صفحه راه‌اندازی**: ماژول‌های مرتبط با کسب‌وکار مشتری را انتخاب کنید. با انتخاب حسابداری، یکی از دو حالت را بخواهید — «حسابداری داخلی زیمر» یا «اتصال به نرم‌افزار موجود». هیچ‌کدام پیش‌فرض نیست.
2. ورود به عنوان **مدیرعامل**. داشبورد با خلاصه هوش مصنوعی و هشدارهای شرکت باز می‌شود؛ منو فقط ماژول‌های انتخاب‌شده را نشان می‌دهد.
3. روی هشدار «موجودی زیر حداقل» دکمه **اطلاع به مسئول** را بزنید: پیام از پیش نوشته‌شده برای مدیر خرید باز می‌شود و پس از ارسال، در گفتگوی داخلی می‌نشیند. این لحظه، هوش مصنوعی و گفتگو و خوراک فعالیت را به هم وصل می‌کند.
4. نقش را به **مدیر تولید** تغییر دهید: تابلوی سفارش کار، مراحل خط، BOM و مصرف پارچه در برابر برنامه. یک سفارش کار را جلو ببرید؛ با خروج از برش، پارچه از انبار کم می‌شود و با رسیدن به بسته‌بندی، محصول نهایی به تفکیک سایز اضافه می‌شود.
5. نقش را به **مدیر فروش** تغییر دهید: دفتر سفارش، سایزبندی هر سفارش و لیست قیمت عمده. یک سفارش فروش جدید ثبت کنید و ببینید موجودی قابل فروش، پرونده مشتری، KPI داشبورد و پاسخ دستیار همگی تغییر می‌کنند.
6. **مدیر انبار**: تحویل یک بار را در ماژول توزیع ثبت کنید؛ سفارش فروش پشت آن هم بسته می‌شود.
7. **مدیر مالی**: حالت حسابداری داخلی (دفتر روزنامه و اسناد خودکار ماژول‌ها) و حالت اتصال (وضعیت اتصال، آخرین همگام‌سازی، داده فقط‌خواندنی) را کنار هم نشان دهید.
8. ورود به عنوان **مدیر سیستم**، در نقش‌ها یک دسترسی را برای مدیر فروش خاموش کنید و سپس به آن نقش سوییچ کنید. رابط بلافاصله تغییر را نشان می‌دهد.

## Notes

- All data is mock and lives in the browser. Reloading resets the demo.
- The assistant has no LLM behind it. It matches the question against the demo dataset and refuses anything it cannot ground.
- The entry screen's right panel is drawn in CSS/SVG, not fetched, so the demo never opens on a broken image on a locked-down client network. To use real factory photography, bundle it under `public/` and replace `BrandPanel` in `src/pages/DemoEntryPage.tsx` — do not hotlink it.
